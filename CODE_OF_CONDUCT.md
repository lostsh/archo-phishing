# Code de conduite

Ce projet adopte le [Contributor Covenant, version 2.1](https://www.contributor-covenant.org/fr/version/2/1/code_of_conduct/).

En résumé, on s'engage à faire de ce projet un espace accueillant pour tout le monde, quels que soient l'âge, le handicap, l'origine, l'identité ou l'expression de genre, le niveau d'expérience, la religion ou l'orientation sexuelle.

Ce qui est attendu : bienveillance, respect des points de vue différents, critiques constructives, reconnaissance de ses erreurs.

Ce qui n'est pas accepté : propos ou images à caractère sexuel, insultes, attaques personnelles, harcèlement public ou privé, publication d'informations privées sans accord.

## Signaler un comportement

Contacte le mainteneur en privé via son profil GitHub. Tous les signalements sont traités rapidement, avec discrétion. Les mesures possibles vont du simple rappel à l'exclusion du projet, selon les lignes directrices du Contributor Covenant.
